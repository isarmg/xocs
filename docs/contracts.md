# 数据与请求约定

本页描述服务端、浏览器及离线工具共同遵守的约定。日常操作见[内容管理](usage.md)，实例布局见[配置参考](configuration.md)。

## 内容与身份

站点包含文章、随笔、分类标签、搜索、友链、相册、家庭、信笺、祝福板、匿名评论和留言。唯一管理员负责后台管理；访客以匿名身份参与互动，无需注册。

文章列表、正文、搜索和评论分别检查内容可见性与访问密码。受密码保护文章的公开列表不返回正文摘要，正文需通过密码验证；评论只接受公开、无密码且允许评论的文章。回复目标必须属于同一内容及评论类型，客户端不能自行指定作者身份。

所有日期输入、显示和日志日界统一为 UTC。没有时区的数据库时间和日期输入也按 UTC 解释，一天固定为 24 小时。

## 重试与幂等

匿名评论、留言与祝福请求携带小写 UUIDv4 的 `request_id`。该标识与内容、目标及父评论绑定，提交收据与评论在同一事务内保存。并发重试、进程重启或响应丢失后，用同一标识重试会返回原提交；同一标识用于不同内容，或原提交已经删除时，返回 `409 Conflict`。

新建文章和文章“最新进展”的请求可通过 `Idempotency-Key` 携带提交标识，浏览器为这些操作生成并保留标识。键须为 1–128 个可打印非空白 ASCII 字符；不带键的请求不提供提交去重。文章键绑定完整提交内容，进展键绑定文章、正文和时间，收据与业务内容在同一事务中保存。同一草稿的失败重试继续使用原键；修改草稿或确认成功后有意再次发布时使用新键。不同内容复用键，或原内容已经删除时，返回 `409 Conflict`。

页面显示“尚未确认”时，应先确认原提交，避免为同一操作生成新标识。HTTP 请求的 `X-Request-ID` 用于关联日志和错误，与上述持久化提交标识分别使用。

## 容量与错误

公开写入共用有界容量：最多 4 个请求执行、32 个请求等待，等待最多 10 秒。容量耗尽或等待超时返回 `503 Service Unavailable`。文章密码计算在独立阻塞任务中执行，最多 2 个并发，并在计算结束后释放容量。

内容接口的 JSON 请求体必须在开始读取后的 10 秒内完整接收；持续缓慢发送不会延长此期限。超时返回 `408 Request Timeout` 并关闭 HTTP 连接，不进入业务处理，同时释放写入容量。该期限只约束输入读取，不中断已开始的事务提交。

公开写入的容量控制不使用访客 IP、账号候选字符串或代理头作为计数身份。认证、同源检查、CSRF 和内容权限仍在各自的请求边界执行。

## 站点媒体

公开站点信息和后台站点设置均返回 `media` 对象。后台保存时必须提交该对象；其字段为可空 URL 字符串：

| 字段 | 展示位置 |
| --- | --- |
| `logo` | 站点标志 |
| `journey_background` | 时间轴背景 |
| `journal_background` | 随笔背景 |
| `guestbook_background` | 留言板背景 |
| `love_letter_background` | 恋爱笔记信笺背景 |
| `love_moments_cover` | 恋爱笔记“点点滴滴”栏目封面 |
| `love_photos_cover` | 恋爱笔记“时光相册”栏目封面 |
| `love_wishes_cover` | 恋爱笔记祝福栏目封面 |
| `toolbox_background` | 百宝箱横幅背景及视频封面 |
| `toolbox_video` | 百宝箱横幅视频 |

`background_image`、`avatar` 和 `random_cover` 继续分别表示首页背景、站长头像和随机文章封面；家庭资料的 `bg_cover` 表示“家”页背景。空白媒体地址保存为 `null`，清空配置不会恢复内置图片或视频。媒体地址只接受 HTTP(S) 或站点根路径，拒绝其它协议、协议相对地址和控制字符。

管理员图片上传入口为 `POST /api/v1/content/upload`，支持 PNG、JPEG、GIF、WebP，最大 10 MiB；视频上传入口为 `POST /api/v1/content/upload-video`，支持 MP4、WebM，最大 50 MiB。服务端按实际文件内容判断类型，使用内容摘要命名，不能用文件扩展名或请求 MIME 绕过类型检查。本地资源被站点外观或其它当前内容引用时，删除返回 `409 Conflict`。

## 数据库与离线操作

数据库身份为 `blog-db-v2`，结构修订号为 `2`。程序校验 `product_metadata`、全部 SQL 对象及当前结构摘要；结构不匹配时拒绝打开。服务启动只打开已初始化的实例。新数据库由显式 `blog-setup initialize` 创建，已有数据库不会被覆盖初始化。

服务与 `blog-setup` 共用实例锁。离线检查先创建 `ROOT/run` 下的受限临时快照，在快照上验证数据库结构、内容和凭据，不改写源数据库。密码重置使用事务更新管理员凭据并撤销会话。具体命令见[运行与排障](operations.md)。
