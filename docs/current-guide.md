# 当前行为与数据合同

前台提供公开文章、随笔、分类标签、搜索、友链、相册、家庭、祝福板、匿名评论和留言。管理后台控制这些业务；没有会员系统、社区用户管理、微言、关于页面或聊天接口。

公开文章必须满足发布、可见与密码规则；匿名评论拒绝自报作者身份，父评论必须属于同一内容。提交 UUID 仅用于持久幂等，不充当可替换的限流身份。重复请求在并发、重启和丢失响应后仍返回同一提交；内容变化或已经删除的收据冲突保持 409。

文章进展的新建请求使用 `Idempotency-Key`：同一草稿的失败重试保留原键，修改草稿或确认成功后再次发布使用新键，允许有意发表相同内容。服务将键与文章、正文和时间绑定；不同内容复用或原进展已删除返回 409，不重复插入。收据与进展在同一事务提交，删除后的收据按匿名评论的现有语义保留。

当前结构新增 `article_news_submission`，schema SHA-256 随之变化。旧结构数据库会被拒绝打开；不执行自动迁移或重置。

Server 不使用访问者 IP、账号候选字符串或代理头计数。公开写入采用有界全局容量（4 个执行、32 个等待、等待最多 10 秒）；文章密码计算在独立 blocking worker 中执行，最多 2 个并发，worker 结束后才释放容量。资源繁忙返回 503，认证和业务权限照常检查。

管理员是唯一站点管理身份，使用公共 SQLite 管理、会话和审计表。当前数据结构为 xocs-db-v1，精确校验 product_metadata 和全部 SQL 对象；删除 member_login_failures。服务启动与辅助程序都不会读取或转换旧结构、自动建表或重新初始化已有数据。

安装、检查、离线凭据维护和升级入口均由 xssi 提供。只读检查使用 ROOT/run 临时快照，不改源数据库或恢复日志。升级只替换SHA-256 文件清单中的程序文件，保留配置、媒体、数据库与业务密钥。支持范围见[部署说明](../deploy/linux-x86_64/README.md)。
