# xocs 当前实现参考

本文面向接口与前端开发者。日常发布内容见[使用指南](usage.md)，部署参数见[配置参考](configuration.md)。

## 功能

- 博客：可配置的首页栏目与推荐位、文章与分类、标题优先的全文搜索、Markdown 目录与阅读进度、访问密码、评论、收藏、友链、音乐、旅拍和恋爱笔记。
- 匿名互动：文章评论、评论回复、祝福板评论和留言板弹幕均无需账号；后台统一管理内容。
- 管理后台：数据总览、首页栏目顺序、文章和分类标签、用户状态、评论、动态与留言审核、网站设置、友链、恋爱笔记、图片上传及资源管理。

当前前台采用匿名互动，后台使用管理员认证。当前数据库格式为 `xocs-db-v4`，运行前校验完整结构。访客发布不使用账号 Cookie，新评论与弹幕的 `user_id` 为空，评论频率按来源 IP 限制；配置可信代理时按代理提供的已校验访客 IP 独立计数。弹幕仍按连接对端限流。

后台使用与其它 Server 相同的公共页头和内容区。主导航分为总览、内容、社区、资源和设置，各组通过二级导航进入管理页面；原有 `/admin#页面` 链接仍可直接访问。统计、表单和分页支持中英文、浅色与深色模式及手机布局。

前台内容区随屏幕展开，宽屏上限为 1920 像素，首页、文章列表、相册与随笔使用自适应网格；手机端自动调整栏目顺序。语言切换和太阳/月亮主题切换位于顶部导航，使用与菜单文字同高的无边框图标。首页文章卡片仅展示标题、封面和元信息，标题保持单行，超长标题自动往返滑动；启用减少动态效果时可横向滚动标题。游记使用桌面五列蛇形时间线，封面显示框为 3:2，以等比缩放覆盖画框，窄屏自动改为三列或两列。

“家”页采用双头像背景、波浪过渡、居中计时、信笺入口和三个图文标签，展示管理员的一份人物与故事资料、按年、月、日、时、分、秒显示的相伴时间、相册、日常记录和祝福板，支持图片预览与内容分页。仅管理员可创建、编辑或删除家的资料；重复创建返回 409，并发创建也只允许成功一次。历史多份资料仅以管理员最新的一份为当前家，隐藏后不回退展示旧故事，其他用户的资料不公开，也不能通过当前管理接口编辑。菜单使用半透明深色背景与磨砂模糊效果，下滑时自动隐藏，上滑或回到顶部时显示；手机展开菜单时保持可见。导航各项直接跳转，不提供下拉菜单；手机通过菜单按钮展开完整导航。“百宝箱”以收藏集为默认内容，统一提供收藏集、音乐和友人帐三个标签。

## 当前中立接口与初始化

当前版本只使用 `.state-instance.lock`、`.state-maintenance.lock`、`.state-maintenance-pending.json` 和 `.state-atomic-` 临时文件前缀。服务身份头为 `x-service`，健康状态中的公共源码修订字段为 `common_revision`。管理会话采用 `__Host-admin-xocs-session`，显式开发模式采用 `admin-xocs-session`；生产 Cookie 的 Secure、HttpOnly、SameSite、Path 和 CSRF 约束继续生效。资源清单格式为 `web-assets-v1`，公共数据库内部表及索引采用 `_common_` 前缀。

当前数据库为 `xocs-db-v4`、结构修订 `4`，实际 DDL 由 `build.rs` 组合并重新计算指纹。校验不符时只读失败，保留原状态；首次部署按[安装指南](getting-started.md)创建新状态。不同结构的程序使用独立数据目录。

v3 移除停用的会员会话、会员写入额度、会员图片及五张聊天表。`member_login_failures` 继续用于匿名互动与文章密码限流，管理员认证仍由公共 `_common_` 表承担。

收藏、友链和音乐使用 `/api/v1/links/page`，分别指定 `kind=favorites`、`friendUrl`、`funny`，每页 24 条并提供上一页/下一页入口；页面分别为 `/favorite`、`/favorite?tab=friends`、`/favorite?tab=music`。旧页面别名 `/friend`、`/music` 已删除；没有生产调用的 200 条单页接口 `/api/v1/links` 也已移除，全部使用分页接口。微言 `/weiYan` 和关于 `/about` 均保留并进入公开菜单，随笔使用 `/api/v1/notes/page`，文件管理使用受管理员认证保护的 `/api/v1/content/resources`。停用的公开 `/api/v1/resources`、`/api/v1/friends` 和 `/api/v1/notes` 返回 404。站点设置仅保留名称、标题、公告、页脚、背景、站长头像和随机封面；文章进展只返回 `id`、`content`、`create_time`，家资料不再返回点赞计数。

## 评论来源与重试契约

直连时默认忽略全部转发头，使用连接对端 IP。HTTPS 反向代理部署需显式配置 `trusted_proxies`，例如 JSON 的 `"trusted_proxies":["127.0.0.1"]`，CLI `--trusted-proxies 127.0.0.1`，或环境变量 `XOCS_TRUSTED_PROXIES='["127.0.0.1"]'`。只允许列出的精确代理 IP，不隐式信任回环、内网或转发链。

可信代理必须覆盖客户端提供的 `X-Real-IP`，发送单个有效 IP；缺失、重复、带逗号或无效值均拒绝。`Forwarded` 和 `X-Forwarded-For` 不参与来源选择。代理入口应直接接收访客连接；多级代理需由管理员在最末一跳可靠解析并覆盖来源。将服务绑定回环或限制为只有可信代理可访问。Nginx 示例见[部署说明](../deploy/linux-x86_64/README.md)。匿名评论限额为每个来源 IP 每 15 分钟 10 条，文章、祝福板和留言评论共用该访客额度。

三个评论 POST 入口都要求 `request_id`（小写 UUIDv4）。评论首尾按 Unicode `White_Space` 去空白（与 Rust `str::trim` 一致），保留正文内部空白及 U+FEFF。一次用户提交生成一个身份，内容、所属文章/板块和回复目标不变时重试必须复用它；新提交才生成新身份。服务在一个事务中写入评论、限额和持久回执；并发或重启后的相同重试返回原评论且不再占用额度。同一身份配不同内容返回 409。回执不随评论删除：原评论已删除时重试返回 409，不重新发表；回执仅存请求摘要与评论引用。

浏览器在发送前将身份和草稿存入当前标签页的 sessionStorage。网络中断、服务异常或无效成功响应显示“尚未确认”，锁定原稿并提供“确认原提交”，不会自动重发。刷新当前标签页后可继续确认；成功后清空待确认状态。明确的首次拒绝保留可编辑草稿。关闭标签页会结束浏览器侧记录；主动清除待确认状态需先确认“评论可能已经发表”的提示并清空草稿。无法保存记录时不会发送。前端所有公开成功响应均经过当前读模型校验，结构无效时报告独立的响应契约错误。

文章列表继续使用 `page`、`size`、`total` 分页。空搜索借助现有最新文章索引分别读取公开及受密码保护文章；先选出当前页 ID，再读取摘要、分类和评论数。搜索仍按标题优先、创建时间及 ID 倒序，数据库 Schema 不变。总数与 OFFSET 仍随命中规模增长，不能视为恒定时间分页。

文章访问密码按 UTF-8 字节校验：12–1024 字节，不包含 ASCII 控制字符。四个汉字（12 字节）可以作为密码；编辑已有受保护文章可留空保留密码，公开文章转为受保护文章必须填写新密码。文章最后更新时间使用 UTC 显示。后台列表、统计、设置和变更回执在交给组件前完整校验当前 DTO，缺失字段、字段类型错误或无效分页元数据均作为响应合同错误处理。
