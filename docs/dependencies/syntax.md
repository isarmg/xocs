# 编译期语法

[syntax 目录](catalog.md#syntax)列出 Rust token、语法树、引用模板、结构派生和宏辅助实现。

`token-stream` 表示编译器 token，`rust-parser` 解析 Rust 语法，`token-templates` 生成 token。派生器通过这些接口生成目标包能解析的真实类型路径；公开接口中的类型身份由对应运行库所有。组件、序列化、数据库记录和资源编译各有明确的宏所有者。

部分解析器和迭代工具按 CSS、记录派生或通用编译用途分别提供。调用者应选择自己管线的依赖，避免为了复用一个 helper 引入整个不相关编译器。过程宏在 AMD64 Linux 构建宿主执行，即使其生成代码用于浏览器 WASM。

添加或修改宏时，至少检查其实际消费者的展开和目标编译。普通 token 生成正确不代表生命周期、泛型、属性或类型路径都有效；支持范围以现有消费者及其注册测试为准，验证命令见[开发说明](../development.md)。
