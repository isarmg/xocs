# 发布和管理内容

先完成[首次运行](getting-started.md)，通过站点的 `/admin` 登录。后台按“总览、内容、社区、资源、设置”组织；顶部提供语言和明暗主题切换。

## 发布一篇文章

1. 在内容管理中准备分类和需要的标签。
2. 新建文章，填写标题、Markdown 正文、分类和展示设置；需要图片时先在文件管理上传。
3. 保存后回到文章列表，核对标题、状态和分类。
4. 打开前台文章页，检查正文、图片、目录和手机布局。仅在前台可见后才把链接分享给读者。

访问密码和公开状态会影响读者能否看到正文，发布前一并核对。删除内容前确认目标；管理页面的删除操作会改变站点数据。

## 上传图片和维护资源

在“文件管理”选择 PNG、JPEG、GIF 或 WebP 图片并上传，复制成功后显示的地址到封面或正文。
在“内容资源”选择友链、收藏、照片或音乐与趣味，填写标题、目标地址和图片，按需要勾选“公开显示”。
保存后在列表核对类型和状态；待审核友链可使用“审核通过”。

## 调整首页和恋爱笔记

在设置中调整首页栏目顺序及站点信息，保存后刷新前台核对。“家”仅允许管理员创建和维护一份资料，包含人物信息、故事、起始时间和倒计时。后台自动打开已有资料供编辑；保存后检查前台“家”页的展示状态。访客可浏览相册、日常记录和发送祝福，不提供入住或创建入口。

## 管理互动内容

文章评论、评论回复、祝福板和留言板支持匿名互动。后台的评论、动态和留言页面按内容类型查看、审核或删除；显示“匿名访客”是正常状态。

访客提交后如果看到“尚未确认”，应在原标签页使用“确认原提交”。浏览器会保留原稿和提交身份；刷新同一标签页仍可继续确认。另发一条相同评论可能产生重复内容，因此先确认原提交的结果。详情见[评论参考](current-guide.md#评论来源与重试契约)。

## 修改管理员账号

按[账号设置](account-settings.md)修改用户名或密码。保存后按页面提示重新登录，再确认后台仍可访问。

如页面加载或保存失败，保留错误提示及请求 ID，按[运行维护与排障](operations.md)检查。
