# 发布和管理内容

先完成[首次运行](getting-started.md)，通过站点的 `/admin` 登录。后台按“总览、内容、社区、资源、设置”组织；顶部提供语言和明暗主题切换。

日期和时间统一使用 UTC，包括文章进展的时间输入。页面会标明 UTC，不随浏览器所在地时区切换。

## 发布一篇文章

1. 在内容管理中准备分类和需要的标签。
2. 新建文章，填写标题、Markdown 正文、分类和展示设置；可直接选择封面图片或插入正文图片，也可使用文件管理中已上传的地址。
3. 保存后回到文章列表，核对标题、状态和分类。
4. 打开前台文章页，检查正文、图片、目录和手机布局。仅在前台可见后才把链接分享给读者。

访问密码和公开状态会影响读者能否看到正文，发布前一并核对。受保护文章可填写密码提示，提示显示在读者输入访问密码的页面。编辑文章时可新增、编辑或删除“最新进展”，列表支持分页，时间按 UTC 输入；新增留空使用当前时间，编辑留空保留原时间。切换进展页码或重试读取不会清空未保存的进展草稿。删除内容前确认目标；管理页面的删除操作会改变站点数据。

## 上传图片和维护资源

在“文件管理”选择 PNG、JPEG、GIF 或 WebP 图片并上传，复制成功后显示的地址到封面或正文。
不再需要的文件可在列表中确认删除。仍被文章、随笔或其它站点内容引用的文件不能删除；先在对应管理页面移除引用，再刷新文件列表并重试。记录发生变化或文件不满足安全要求时也会保留文件，成功删除才会刷新当前页。
在“内容资源”选择友链、收藏、照片或音乐与趣味，填写标题、目标地址和图片，按需要勾选“公开显示”。
保存后在列表核对类型和状态；待审核友链可使用“审核通过”。

## 维护随笔和信笺

在内容菜单的“随笔管理”新增或编辑正文、选择图片上传，并设置公开或私密状态。列表还提供公开、隐藏和删除操作；随笔同时用于前台随笔页和“家”的日常记录。取消编辑可放弃未保存的修改，分页或读取重试会保留草稿。

在“信笺管理”填写收信人、署名与正文，勾选“公开显示”后保存。前台信笺读取实际保存的内容；隐藏后显示未发布状态，保存失败会保留当前输入。

## 调整首页和恋爱笔记

在设置中调整首页栏目顺序及站点信息，保存后刷新前台核对。站长显示名用于文章与随笔署名，和管理员登录名分开设置。“家”仅允许管理员创建和维护一份资料，包含人物信息、故事、起始时间和倒计时。后台自动打开已有资料供编辑；保存后检查前台“家”页的展示状态。访客可浏览相册、日常记录和发送祝福，不提供入住或创建入口。

## 管理互动内容

文章评论、评论回复、祝福板和留言板支持匿名互动。后台的评论和留言页面按内容类型查看或删除；显示“匿名访客”是正常状态。

访客提交后如果看到“尚未确认”，应在原标签页使用“确认原提交”。浏览器会保留原稿和提交身份；刷新同一标签页仍可继续确认。另发一条相同评论可能产生重复内容，因此先确认原提交的结果。请求重试的具体规则见[数据与请求约定](contracts.md)。

## 修改管理员账号

1. 从后台右上角头像打开账号设置。
2. 填写用户名和当前密码；新密码留空则保留现有密码，修改密码时填写两次相同的新密码。
3. 保存成功后，使用新的账号信息重新登录。

用户名使用 3–64 个 ASCII 字符，以字母或数字开头和结尾，中间可包含字母、数字、`.`、`_`、`-`，保存时统一为小写。管理员密码要求 12–1024 个 UTF-8 字节，不能包含 ASCII 控制字符。

保存时先验证当前密码，再原子更新账号并撤销已有会话。失败或离开页面会清除密码输入。页面的语言与明暗主题选择在刷新、登录和退出后保持。忘记管理员密码时，按[运行与排障](operations.md#恢复管理员访问)进行离线重置。

如页面加载或保存失败，保留错误提示及请求 ID，按[运行与排障](operations.md)检查。
