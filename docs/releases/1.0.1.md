# XOCS 1.0.1

本次发行包含最新主线中的文章与分类管理修复，并更新可部署安装包。软件版本为 `1.0.1`；数据库身份继续为 `xocs-db-v1`、结构修订为 `1`，不提供历史结构迁移。

- 修复文章更新与发布重试的幂等处理，以及重复删除、过期删除请求与并发修改的冲突处理。
- 修复分类及标签删除、页面切换时编辑状态丢失或被旧响应覆盖的问题。
- 安装包固定包含已修正配置校验顺序与维护行为的 XSSI 实现，保留管理员控制、服务账号只读的配置权限。
- 更新 rustls 至 `0.23.46`，处理新公布的安全公告。
- 验证真实服务会话与文章数据在进程重启后保持，并在隔离 systemd 环境中检查安装、生产 TLS 登录及已发布内容。

发行目标为 Linux x86_64 GNU。下载归档与同一 Release 的 `SHA256SUMS`，先验证 SHA-256，再按包内安装说明操作；安装不会自动启动或启用服务。已有配置和数据必须满足当前契约，不自动转换或覆盖。
