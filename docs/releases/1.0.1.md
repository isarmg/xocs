# xocs 1.0.1

## 更新

- 上传资源、文章封面和正文图片时保留中文、emoji 与其他 UTF-8 原始文件名。
- 删除分类前检查首页栏目，避免删除最后一个启用的分类栏目后导致首页为空且无法重新保存。
- 文章动态时间在管理页保存、重新加载和公开页显示时统一按浏览器本地时区呈现。
- 评论删除提示区分顶层评论与回复，准确说明删除顶层评论会同时删除该楼层的回复。
- 服务端和管理 Web 公共支撑升级到 `xcss 1.0.2`。

## 下载与部署

提供 Linux x86_64 GNU 归档 `xocs-1.0.1-linux-x86_64.tar.gz` 和对应 `.sha256`。归档包含 `bin/xocs`、嵌入式管理 Web、许可证及构建身份信息。

安装和运行步骤见[部署指南](../../deploy/linux-x86_64/README.md)。
