# xocs 1.0.3

- 首页搜索、文章分类、标签与搜索结果操作保留网址中的显式语言选择。
- 文章列表、搜索结果、时间线和随笔的页码写入网址，刷新或从文章返回时恢复所在页。
- 提交搜索、选择分类/标签与翻页新增可回退的历史记录；后退和前进恢复对应筛选及页码。只编辑搜索草稿或在第 1 页重试同一查询不会新增历史；在其他页再次提交搜索会返回第 1 页。
- 切换分类、标签或提交搜索重置至第 1 页；旧请求晚返回不会覆盖当前筛选。
- 补充公开文章 API 的联合筛选、稳定分页与字面搜索回归，以及 Chromium/Firefox 的网址、语言、刷新和历史回归。

数据库身份仍为 xocs-db-v4、结构修订 4，结构和迁移策略未改变。本地审查版本的 Rust/Web 公共支撑固定 xcss 1.0.7 与 revision b3a68b94e1b7bae53685bae07449e3f78e3c20a8，保留本地已验证的 UTC、完整字体、分页和输入合同修复。
