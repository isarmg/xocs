# xocs 1.0.3

- 首页搜索、文章分类、标签与搜索结果操作保留网址中的显式语言选择。
- 文章列表、搜索结果、时间线和随笔的页码写入网址，刷新或从文章返回时恢复所在页。
- 提交搜索、选择分类/标签与翻页新增可回退的历史记录；后退和前进恢复对应筛选及页码。只编辑搜索草稿或重试同一查询不会新增历史。
- 切换分类、标签或提交搜索重置至第 1 页；旧请求晚返回不会覆盖当前筛选。
- 补充公开文章 API 的联合筛选、稳定分页与字面搜索回归，以及 Chromium/Firefox 的网址、语言、刷新和历史回归。

数据库身份仍为 xocs-db-v4、结构修订 4，结构和迁移策略未改变。Rust/Web 公共支撑仍固定 xcss 1.0.5 与 revision 6a8113d4be76e5e8977ac7be08c1a7c57963ae49，本版本未升级依赖。
