# xocs 1.0.4

- 移除独立用户管理及其接口，管理员账号设置仍通过右侧人物图标进入。
- 删除关于页面、微言入口及相关代码。随笔保留原有内容，并补齐正文、图片、发布状态的编辑功能。
- 所有公开页面删除底部背景页脚，保留圆形返回顶部按钮；站点接口和后台设置移除页脚字段。
- 文件选择按钮使用 xcss 自定义圆角，文件管理增加本地图片删除。删除前检查已保存内容的引用，包括草稿和编码后的图片地址；仍在引用的文件拒绝删除。上传与删除串行执行，文件删除支持中断恢复。
- 后台补齐站长展示名、文章密码提示、文章进展编辑及分页、信笺正文与发布状态管理；前台信笺读取实际保存内容。
- 补充前后端合同、权限、文件生命周期与 Chromium/Firefox 中英文布局回归。

数据库身份仍为 xocs-db-v4、结构修订 4。删除的页脚数据库列及原有数据不作破坏性清理，接口不再接受或返回该字段。公共支撑固定 xcss 1.0.11，revision 53c24a2bc026b3c09e073f18cd26b01d15d6d354。

## 部署与运维合同

- `data_dir` 是唯一内部根，数据库固定为 `site.sqlite`；媒体保留独立业务目录。
- `config validate` 纯配置检查，`check` 离线校验状态，`status` 查询在线就绪状态。
- `admin reset-password --username admin` 从 stdin 读取新密码并撤销会话。
- 默认 info 的 `log_level` 使用统一 xcss UTC 结构日志与私有滚动文件。
- 发行包仅提供 `install.sh setup CONFIG_JSON [USERNAME]` 和 `install.sh upgrade`，普通固定用户 systemd，升级保留配置与状态。
- 真实 IP 统一由 xcss 在 HTTP 边界解析；评论、弹幕、文章密码及管理员认证共用显式可信代理链。
