# XOCS 1.1.0

本次发布包含 Linux AMD64 专用化、Rust 业务与浏览器架构整理，以及仓库内依赖的深度定制。原生发行目标为 `x86_64-unknown-linux-gnu`（GNU/glibc），浏览器界面继续由 Rust/WASM 实现。

- 重构 SQLite 访问与线程交接，修复行共享、协作调度预算及取消场景；会话维护使用有界游标，避免活跃记录阻塞过期会话清理。
- 界面协议收缩为 CSR，移除未使用的服务端渲染、水合与模板路径；修复 DOM 微任务重入调度，保留视图更新、状态复用与生命周期。
- 修复通知回调与 Waker panic 后的状态一致性、SHA-512 后端选择与 AVX2 参数、编译器字符串边界，以及本地时区转换的歧义排序和夏令时边界。
- 拆分独立 JS/CSS 编译管线，复用单次输入快照；开发代理使用连接池和流式转发，静态媒体路径改为共享不可变数据。
- 更新常量时间工具至 `ctutils 0.4.4`，修复 2026-10-23 公布的 [RUSTSEC-2026-0385](https://rustsec.org/advisories/RUSTSEC-2026-0385)：为掩码生成恢复优化屏障，并修正 32 位目标的 `u128` 比较。
- 将密码随机数统一到系统熵实现，裁剪未使用平台、接口与依赖。维护包由 240 个收敛到 229 个，保留原始发布归档、许可证和完整来源记录。

源码版本不再承担旧接口或旧平台兼容目标。数据库结构不作历史迁移；安装、维护及已有数据必须满足当前合同。下载归档与同一 Release 的 `SHA256SUMS`，核对 SHA-256 后按包内说明安装；安装不会自动启动或启用服务。

本次优化已通过原生与 WASM 构建、项目 Clippy、532 项维护回归、CSR 文档测试、Chromium/Firefox 的 14 组场景及真实后端冒烟测试。具体测量口径、性能限制和验证范围见[优化报告](https://github.com/isarmg/xocs/blob/v1.1.0/docs/optimization-linux-amd64.md)。

发布前供应链审计使用 334 个活动原始包身份；升级后漏洞与 yanked 检查通过。审计保留 `paste 1.0.15` 的既有未维护提示（RUSTSEC-2024-0436），没有新增忽略规则。
