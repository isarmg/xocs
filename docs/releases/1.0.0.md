# XOCS 1.0.0

按本次明确授权重新建立发行基线：软件版本为 `1.0.0`，标签为 `v1.0.0`；当前数据库身份为 `xocs-db-v1`、结构修订为 `1`。源码提交历史保留，旧 GitHub 标签、Release 和附件清除。新的发行物必须绑定本次源码、当前安装合同及实际 SHA-256。

运行程序只接受绝对 `--root`，安装、初始化、只读检查和离线凭据维护由独立 XSSI 脚本及同源 setup 辅助程序负责。升级由脚本协调 XSSC 自动停服、检查、备份、替换当前合同的程序并启动验收，不提供历史配置导入、数据迁移或旧版本兼容。

管理员使用主数据库的公共管理表及 Argon2id 哈希；管理员控制配置，服务账号只读。保留登录尝试预算、实例与文件容量及全局资源上限，不识别访问者 IP。公共 HTTP 传输事件与产品事件写入同一受管日志。

本次同时修正当前结构的测试初始化、媒体路径、管理员凭据校验和发行来源闭包。具体操作见[当前指南](../current-guide.md)，包内程序、辅助程序、契约和许可证以实际文件清单核验。
