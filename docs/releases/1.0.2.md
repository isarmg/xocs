# xocs 1.0.2

- 评论末页记录被删除后重新读取仍存在的末页，保留提交结果不确定提示。
- 文章进展首次读取成功前禁止发布；分类、标签及首页栏目的读取重试分别处理，不覆盖编辑草稿。
- 后台分页只显示当前请求对应的记录；删除末页最后一条记录后自动返回有效页。
- 标签分类加载失败时提供独立重试，保留已输入的标签草稿。
- 弹幕与评论复用已配置的可信代理访客地址解析，按实际访客分别计数，发送限额不变。
- 图片预览使用原生 modal dialog；关闭后仅向仍连接的触发元素恢复焦点。
- 搜索词上限按 UTF-16 计数，与页面的 200 maxlength 一致。
- 七类可硬删除内容使用不复用的自增 ID，避免旧操作指向新记录。
- 文章创建支持可选 Idempotency-Key。同 key、同初始请求重放返回已有文章当前内容；不同请求或已删除文章返回冲突。校验失败不占用 key，PUT 更新合同不变。编辑器 key 只在当前组件生命周期稳定，不提供刷新、重挂载或关闭页面后的恢复。
- Rust/Web 统一固定 xcss 1.0.5 与 revision 6a8113d4be76e5e8977ac7be08c1a7c57963ae49。

数据库身份为 xocs-db-v4、结构修订 4。旧 v3 数据库会被拒绝，保留原文件；本版本不提供自动迁移，也不会删除旧数据。实际 schema 指纹由构建生成。

图片预览的打开、Escape 关闭及焦点恢复已通过 Chromium 和 Firefox 回归；Tab 遍历和屏幕阅读器尚未单独验收。
